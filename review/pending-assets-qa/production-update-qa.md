## 접근성 검사와 수정 확인

최초 axe 검사에서 실제 label-content-name-mismatch를 발견했습니다. 언어 선택 버튼의 접근 가능한 이름에 현재 보이는 언어명이 없었고, 러시아어 브로셔 미리보기 버튼의 보이는 문구와 접근 가능한 이름이 달랐습니다. 루트가 두 문구를 수정했으며, 닫힌 메뉴의 불필요한 aria-controls와 generic div에 남은 aria-labelledby도 정리했습니다.

수정 후 `127.0.0.1:4185`의 개발 소스를 axe 4.14로 검사했습니다. **5개 폭 × 3개 언어 15개 상태와 열린 언어 메뉴 2개 상태, 총 17개 상태에서 확정 위반 0건**입니다. 검사 전후 관련 소스 6개 파일의 SHA-256이 같아 검사 중 소스 변경이 없음을 확인했습니다. 문서 가로 넘침도 0건입니다.

자동 판정 보류를 자동 통과로 계산하지 않았습니다. hero 그라디언트와 가로 스크롤 비교표의 대비는 계산된 글자색과 실제 배경색으로 수동 검토했으며, 검사한 조합의 최저 대비는 **6.18:1**입니다. 열린 메뉴의 aria-controls는 실제 보이는 role=menu 타깃, 선택지 3개, 선택된 항목 1개로 연결됨을 직접 확인했습니다. 장식용 체크 표시에는 aria-hidden=true가 적용되어 있으며 Escape 후 버튼 포커스가 복원됩니다.

근거: `accessibility-results.json`(수정 전), `accessibility-final-results.json`(수정 후), `manual-contrast.json`, `manual-aria-controls.json`. 화면 증거는 이 폴더의 `screenshots/`에 있습니다.
